# Support

## Getting help

- **Docs first:** Read [docs/README.md](./docs/README.md) — it answers 90% of “how do I update the README?” questions.
- **Bug or broken link?** Open a **Bug Report** issue (see `.github/ISSUE_TEMPLATE/bug_report.md`).
- **Feature idea?** Open a **Feature Request** issue.
- **Question / discussion?** Use [Discussions](https://github.com/KetanDutt/codeSTACKr/discussions) if enabled, or email **ketan6196@gmail.com**.

## What we help with

- Fixing links, badges, or image rendering
- Improving accessibility or performance of the profile
- Updating YouTube/blog sections via local scripts

## What we don't support

- Adding GitHub Actions / CI — intentionally not supported (see [CONTRIBUTING.md](./CONTRIBUTING.md)).
- Debugging external CDNs (`shields.io` outage, `github-readme-stats` downtime) — we document workarounds in [docs/MAINTENANCE.md](./docs/MAINTENANCE.md).
- Personal fork customization — you're welcome to fork, but we can't maintain every fork.

## Response time

Best effort. Maintainer reviews issues/PRs weekly.

## Security issues

Do **not** open a public issue. See [SECURITY.md](./SECURITY.md).
